# MySQL SOP

通用流程见 [Go 入口](../SKILL.md)，输入安全与验证分别见 [安全](../../common/security/SKILL.md)、[测试](../../common/testing/SKILL.md)。先确认版本、引擎、隔离级别和访问方式，以实际规模和分布评估风险。

## 查询与分页
1. 阅读表结构、索引、调用点、模型映射及事务封装，明确筛选、排序、空值、时区、精度、返回字段和一致性要求。
2. 值使用参数绑定，表名、列名及排序方向使用受控白名单，不能用参数占位符代替标识符。
3. 按谓词、关联和排序核查索引列顺序、选择性、隐式转换及回表成本；用执行计划验证扫描量与结果放大，未知生产索引不推定存在。
4. 列表有最大页大小及唯一稳定排序；复合游标包含排序键和唯一决胜键，续页条件匹配方向与空值语义。并发插入或排序字段更新下，稳定排序不等于快照一致性。
5. 浅分页可保留 offset；深分页量化扫描代价并评估游标或结果快照。不默认无限返回、无限 preload 或循环 N+1。
6. 遵循项目 SQL 集中位置，在常量旁说明用途及索引、分页、事务或降级前提；联查字段类型、外键、扫描顺序和 tag，ORM 限制字段选择。

## 写入与故障边界
- 原子数据库操作置于短事务，固定加锁顺序、校验受影响行数；事务内不等待外部 HTTP、消息确认或长时间计算。
- 更新删除限制范围，禁止无保护大范围写；批处理明确批大小、提交边界、进度及恢复方式。
- 死锁或瞬态错误按完整事务和业务幂等重试，限制次数及总预算；提交超时不等于回滚，通过业务键查询或幂等重试确认。
- I/O 传递 context，设置超时和连接池上限，处理 rows 关闭、迭代错误及回滚清理。
- 写后沿用缓存失效或事件发布策略，明确跨系统一致性窗口。
- DDL 评估锁表、复制延迟、迁移兼容与回退条件；会实际执行查询的计划分析先确认安全范围，不直接用于生产高风险语句。

## 性能与验证
- 大表 Join 评估驱动表、索引顺序及结果放大，必要时比较反范式、预计算或分步查询；统计、计数、排行评估缓存、异步汇总或离线聚合。
- 高频写评估热点行/索引、唯一键冲突、重试放大及 binlog/复制压力，不为优化改变过滤、排序、事务或公共错误语义。
- 覆盖参数绑定、字段映射、分页边界、并发更新、死锁重试、取消、部分批次失败及提交未知。
- 用代表性数据比较扫描/返回行数、P95/P99、锁等待、连接池等待及复制压力，记录索引前提和迁移影响。
