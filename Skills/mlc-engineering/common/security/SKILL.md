# 安全检查流程

## 信任与权限
- 沿入口、存储和日志识别不可信输入、敏感资产，以及身份、角色、租户、对象和外部服务边界。
- 服务端验证身份、角色与对象归属，覆盖横向/纵向越权、跨租户和批量逐项授权；隐藏按钮不是权限控制。
- 核对令牌过期、撤销、刷新和登出，失败不默认放行；Cookie 会话检查 CSRF、安全属性及跨域策略。
- 沿用现有安全设施及后端签名契约，不自创密码算法、绕过认证或以关闭证书校验解决问题。

## 隐私与秘密
- 最小化数据收集、传输和保留，明确用途与删除路径；检查本地存储、备份、共享及用户隔离。
- 秘密使用既有管理设施，不硬编码或提交；日志、异常、分析事件和夹具不含密码、令牌或完整个人信息。
- 发现泄漏时停止扩散，不复述秘密，按项目流程通知与处置。

## 输入与注入
- 在信任边界校验类型、长度、范围和允许值，不信任客户端声明。
- SQL 参数绑定，命令使用结构化参数；页面按上下文编码，富文本用受维护的清理方案。
- 文件限制目录、类型及大小，检查穿越和符号链接；外部 URL 限制协议、目标、重定向与内网访问。
- 反序列化、模板和动态执行禁用不必要能力。

## 验证与变更
- 补未登录、无权限、跨租户、恶意输入及敏感日志等负向用例，执行遵循 `testing`。
- 攻击路径只在授权隔离环境验证；安全边界、秘密轮换和生产数据操作先确认影响与授权。
- 采用最小可验证控制，不附带升级或引入整套依赖；记录风险和未验证边界，静态无告警不等于安全保证。
