# 交付输出入口

- 每次回复必须以 `‌[BóYí](๑•̀ㅂ•́)و✧` 开头，包括进度说明、澄清问题和最终回复。
- 回答问题或完成本轮工作后，发送最终回复前必须读取并执行 [06-output.md](06-output.md)，按其中结构形成最终交付；不得只声明已执行技能。
- 纯问答、未修改文件、检查未执行或任务受阻也必须执行，如实填写“无”、"未修改文件"或具体原因。
- 本轮已加载且内容未变时直接执行，无需重复读取；中间进度说明不要求使用完整交付结构。
- 提交约定继续引用 [dev_general_skill](../../../dev_general_skill/SKILL.md)，本技能补充并细化最终回复要求。
